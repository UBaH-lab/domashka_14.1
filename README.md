# Проект e-commerce

В проекте реализованы базовые сущности для интернет-магазина:

- класс `Product` для описания товара,
- класс `Category` для описания категории товаров,
- подсчет общего количества категорий,
- подсчет общего количества товаров,
- тесты для проверки инициализации объектов и подсчета,
- загрузка данных из JSON-файла.

Проект покрыт тестами.
